# 💍 Destiny – Wedding Planning Website

A wedding planning website developed using **HTML and CSS**, designed to help users explore different wedding ceremonies, discover ideas and find inspiration for making their special occasions memorable.

## 🖥️ Project Overview

**Destiny** is a multi-page wedding planning website that brings together different wedding-related events and arrangements in one place. It provides sections for engagement, pre-wedding shoots and traditional wedding ceremonies, along with pages for user registration, login, contact and feedback.

## 🛠️ Technologies Used

- **HTML5** – Structure and content of the website.
- **CSS3** – Styling, layouts, animations and visual presentation.

## ✨ Key Features

- 💍 **Engagement Planning** – Explore invitation designs, outfits, hairstyles, decorations, food, rings, cakes and photography.
- 📸 **Pre-Wedding Shoot Ideas** – Explore themes, locations and outfit inspiration.
- 🎉 **Wedding Ceremony Sections** – Browse different traditional wedding functions.
- 🌼 **Traditional Functions** – Includes Haldi, Sangeetha, Mehendi and other ceremonies.
- 🎨 **Visual Navigation** – Image-based navigation to explore different wedding categories.
- 🔐 **Login & Registration Pages**
- 🔑 **Forgot Password Page**
- 📞 **Contact Page**
- 📝 **Feedback Form**

## ⚙️ How It Works

1. **Welcome Page:** Users enter the website through the Destiny landing page.
2. **Explore the Menu:** Navigate through the available wedding planning categories.
3. **Engagement:** Explore ideas related to invitations, costumes, hairstyles, decorations and more.
4. **Pre-Wedding Shoot:** Discover different themes, locations and outfit ideas.
5. **Wedding Functions:** Explore traditional ceremonies such as Haldi, Sangeetha, Mehendi, Reception and Muhurtha.
6. **User Access:** Navigate through login and registration pages.
7. **Feedback:** Use the feedback section to share suggestions.

## 🚀 How to Run the Project

**Prerequisites:**

- Visual Studio Code
- Any modern web browser
- Live Server Extension (Recommended)

**Steps:**

1. Clone the repository:

   ```bash
   git clone https://github.com/dhanushree4406/Destiny.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Destiny
   ```

3. Open the project folder in **Visual Studio Code**.

4. Open `index.html` using **Live Server** or directly in your browser.

5. Explore the different wedding planning sections!
